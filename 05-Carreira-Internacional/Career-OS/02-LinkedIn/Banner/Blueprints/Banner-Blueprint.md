---

# 🌍 Purpose

The Banner Blueprint defines the visual architecture of Yuri Bruno's official professional banner.

This document is the technical reference used to build banners for LinkedIn, GitHub and the Portfolio Website while keeping one unified visual identity.

---

# 🎯 Design Objective

Communicate, in less than three seconds:

- AI Engineering
- Backend Engineering
- AI Automation
- Global Career
- YUYU AI Studio identity

---

# 🧠 Visual Concept

The visual identity combines:

- Artificial Intelligence.
- Software Engineering.
- Premium technology aesthetics.
- Global opportunities.
- Learn in Public philosophy.

The banner must feel modern, technical and minimal.

---

# 📐 Layout Blueprint

The banner uses a 12-column layout divided into three major zones.

| Zone   | Purpose                               |
| ------ | ------------------------------------- |
| Left   | Brand identity (YUYU AI Studio).      |
| Center | Main professional message.            |
| Right  | Skills and global career positioning. |

---

# 🟪 Left Zone

Primary content:

- YUYU AI Studio.
- Logo.
- AI visual identity.
- Purple glow.

Purpose:

Immediate brand recognition.

---

# 🔵 Center Zone

Main headline.

Primary message:

> Building AI Solutions for Businesses

Secondary message:

> People. AI. Real Impact.

Purpose:

Professional positioning.

---

# 🟢 Right Zone

Technical positioning.

Topics displayed:

- AI Engineering.
- Backend Engineering.
- Automation.
- APIs.
- FastAPI.
- PostgreSQL.
- Open to Remote Opportunities.

Purpose:

Communicate specialization.

---

# 🌌 Background System

The background contains four visual layers.

| Layer   | Description                         |
| ------- | ----------------------------------- |
| Base    | Dark navy background.               |
| Layer 2 | Purple/blue gradient.               |
| Layer 3 | Neural network patterns.            |
| Layer 4 | Glow particles and subtle textures. |
