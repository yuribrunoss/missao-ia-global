> **Version:** 2.0.0

---

# 🌍 Purpose

This document defines the technical specifications required to build, export and maintain the official professional banner used across LinkedIn, GitHub and the Portfolio Website.

---

# 📏 Official Export Sizes

| Platform  | Resolution    | Aspect Ratio |
| --------- | ------------- | ------------ |
| LinkedIn  | 1584 × 396 px | 4:1          |
| GitHub    | 1600 × 400 px | 4:1          |
| Portfolio | 1920 × 600 px | 16:5         |

---

# 🛡 Safe Area

Important information must remain inside the safe area to avoid cropping.

| Element       | Recommendation |
| ------------- | -------------- |
| Left Margin   | 140 px         |
| Right Margin  | 140 px         |
| Top Margin    | 48 px          |
| Bottom Margin | 48 px          |

Never place text or logos outside the safe area.

---

# 🧩 Layout Grid

The banner follows a 12-column grid.

| Zone            | Columns |
| --------------- | ------- |
| Brand Identity  | 1–4     |
| Main Message    | 5–8     |
| Skills & Career | 9–12    |
