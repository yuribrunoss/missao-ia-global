# LinkedIn Premium — Missão IA Global (PT-BR)

## Objetivo

Este módulo centraliza toda a documentação relacionada ao perfil profissional do LinkedIn da Missão IA Global.

## Estrutura

* Banner → Identidade visual do LinkedIn.
* Headline → Título otimizado para recrutadores.
* About → Resumo profissional internacional.
* Featured → Portfólio em destaque.
* Experience → Experiência profissional.
* Certifications → Certificados e credenciais.
* Networking → Estratégias de networking.
* Posts → Conteúdo e publicações.

## Idiomas

Cada documento possui uma versão oficial em inglês e uma versão em português (`*.pt-BR.md`).
