# Learning in Public

## Filosofia

Acredito que Engenharia de Software é aprendida construindo projetos reais e compartilhando a evolução.

A Missão IA Global documenta toda minha jornada de Engenharia de IA.

Cada Sprint é registrada.

Cada arquitetura é documentada.

Cada projeto evolui publicamente.

## Objetivos

* Construção de portfólio.
* Aprendizado contínuo.
* Open Source.
* Documentação de engenharia.
* Evolução profissional internacional.
