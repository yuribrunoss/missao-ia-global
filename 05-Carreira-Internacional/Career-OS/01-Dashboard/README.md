# Career OS — Dashboard

> Mission Control Center for the international AI Engineering journey.

## Overview

The Dashboard module is the central operating system of the Career OS. It connects LinkedIn, GitHub, Portfolio, Resume, Networking, Applications, Interviews and English into a single roadmap.

Everything inside Career OS starts here.

## Objectives

* Track weekly goals.
* Measure KPIs.
* Monitor international applications.
* Track interviews.
* Track certifications.
* Monitor portfolio progress.
* Monitor GitHub growth.
* Monitor LinkedIn growth.
