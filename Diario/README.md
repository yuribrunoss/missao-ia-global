> **Version:** 2.0.0
> **Status:** 🟢 Active

---

# 🎯 Purpose

The Engineering Journal records the complete development history of the Missão IA Global project.

Every work session generates a daily engineering log, while every completed sprint generates a Sprint Review document.

This module acts as the historical memory of the project.
