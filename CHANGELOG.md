# v4.0.0 — Volumes 1-4 shipped: AI Feedback Classifier in production (2026-09-22)

## Added

- Volume 1 — Python for AI: first CLI classifying customer feedback sentiment via the Gemini API.
- Volume 2 — Automation: suggested replies + automatic "ação pendente" for negative feedback.
- Volume 3 — AI Agents: decision via Gemini function calling instead of a fixed rule, plus memory/context (agent can consult similar past cases before deciding).
- Volume 4 — Backend AI: PostgreSQL replacing SQLite, Docker + docker-compose, managed Postgres on Render via `render.yaml`.

## Changed

- README, ROADMAP and PROJECT-MAP corrected to reflect the real status of each volume (previously some files still listed Volumes 1-4 as "planned", and disagreed with each other on what each volume number meant).
- Removed unearned/aspirational claims from documentation: fictional progress percentages, "Premium" status labels not tied to a real deliverable, and wrong folder names in the repository tree (`02-APIs-Automation` → `02-APIs-e-Automacoes`, `03-AI-Agents` → `03-Agentes-IA`).

## Status

🟢 Shipped — validated end-to-end in production, including surviving a manual redeploy.
