# 📐 Icon Usage Rules

Maximum one icon per title.

Do not mix icon styles.

Use icons before titles only.

Icons must reinforce meaning, not decoration.

---

# 🚫 Avoid

Random emojis.

Country flags as UI icons.

More than three icons in one paragraph.
