# 🌍 Typography Philosophy

Typography should communicate professionalism, clarity and consistency.

The same typography rules apply across GitHub, LinkedIn, documentation and applications.

---

# Primary Font

## Inter

Purpose:

- Headings.
- Paragraphs.
- Documentation.
- Portfolio.
- LinkedIn.

Characteristics:

- Modern.
- Clean.
- Excellent readability.

Weights used:

300 — Light

400 — Regular

500 — Medium

600 — Semibold

700 — Bold

# Secondary Font

# Code Style

Always use fenced code blocks.

Example:

```python
print("Missão IA Global")
```

Language identifier is mandatory.

4.5:1

1.5 line-height
